# The ordering of quadrature operators is fixed in the current implementation, so the commutation relations always take the form:
	[r_j,r_k] = i*Ω_jk where the symplectic form is Ω = ⊗_{j=1}^N [[0,1],[-1,0]].
In order to allow for other orderings, it should be possible to submit a desired symplectic form Ω to represent alternate commutation relations.
# {ermute method to reorder FLS and CVS modes.
# Implement some magic methods. str, repr, maybe iter, setitem, delitem. matmul and rmatmul as tensor shorthand.
# Confirmation: The application of the canonical commutation relation is obtained using the following:
        ½r_j*r_k*O(2)_jk 
        = ½r_j*r_k*(O(2)_jk + O(2)_jk^T)/2 + ½r_j*r_k*(O(2)_jk - O(2)_jk^T)/2 
        -> data_2nd = (O(2)_jk + O(2)_jk^T)
    And we now move to the asymmetric part, using r_j*r_k-r_k*r_j = i*Ω_jk, using the fact that the labels are 
    arbitrary and Ω_jk = -Ω_kj:
        ½r_j*r_k*(O(2)_jk - O(2)_jk^T)/2 
        = r_j*r_k*(O(2)_jk - O(2)_kj)/4 
        = (r_j*r_k*O(2)_jk - r_k*r_j*O(2)_kj - i*Ω_jk*O(2)_kj)/4 
        = -i*(Ω_jk*O(2)_kj)/4 
        = -i*(Ω_jk*(O(2)_kj-O(2)_kj^T))/8
